# Risks

- **Security Review**: Fehlanforderung von 6 Wochen Zeit für Security Review, was die MVP-Zeitlinie sprengt.
- **Overengineering**: Überkomplizierte Lösungen können zu Verzögerungen führen und den MVP-Termin gefährden.
- **Compliance**: DSGVO-konforme Umsetzung kann zusätzliche Zeit erfordern, was die 8 Wochen MVP-Zeitlinie belastet.
