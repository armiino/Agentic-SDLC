# Architektur
## Systemarchitektur:
- Das System wird bestehen aus einem Kundenportal für Benutzerinteraktion, einem Backend-Subsystem zur Datenverwaltung sowie einer SAP-Integration für Produktinformationen und Preise.

## Komponentenbeschreibung:
### Kundenportal:
- Web-basierte Plattform, später native App hinzufügen (nach der Erfüllung des MVP-Zeitplans).
### API Layer:
- OAuth-basierte API-Authentifizierung für sicherheitsrelevante Datenverkehr.

## Technologie-Wahl:
- Managed Services für die Datenbank, um Skalierbarkeit zu gewährleisten und den IT-Budgetrahmen einzuhalten.
