# Anforderungen

## Funktionalanforderungen
- Kundenportal (Web-basiert, möglicherweise später mobile Version)
- Angebote erstellen
- Rechnungsdownload
- Login per E-Mail und Passwort
- Rollenmodell (Admin, normaler User, Manager, Support?)
- Logging
- SAP Integration
- Kein neuer DB Server
- MVP in 8 Wochen
- Security Review
- DSGVO-Konformität
- KPIs (Conversion Rate, Zeit bis Angebot)
- Mobile Version optional
- SSO optional
- API Layer

## Nicht-funktionale Anforderungen
- Skalierbarkeit für 200 - 20.000 Benutzer
- TLS Verschlüsselung
- EU-only Datenhaltung oder DSGVO-konform
- Backup und Disaster Recovery
- Performance

## Einschränkungen/Compliance
- DSGVO (Double-Opt-In, Logging, Löschkonzepte)
- SAP Integration (Audit Trails, Zugriffskontrolle, Rollenmodelle)
