# Architektur
- **Backend**: API Layer mit OAuth-Sicherheit, Managed Services für Datenhaltung (kein neuer DB Server)
- **Frontend**: Kundenportal als Webanwendung, mögliche mobile App in der Zukunft
- **Integration**: SAP Integration für Produktinformationen und Preise, Logging und Audit Trails
- **Sicherheit**: Verschlüsselte Datenübertragung (TLS), Backup und Disaster Recovery
