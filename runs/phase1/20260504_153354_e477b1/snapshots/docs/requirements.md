# Requirements
## Functional Requirements
- Kundenportal mit Login, Rollenmodell (Admin, User, Manager)
- SAP Integration für Produktinformationen und Preise
- Erstellung von Angeboten
- Download von Rechnungen
- Verschlüsselung der Datenübertragung (TLS)
- Logging und Audit Trails
- Backup und Disaster Recovery
- API Layer mit OAuth-Sicherheit
- Push Notifications
- KPIs: Conversion Rate, Zeit bis Angebot

## Non-functional Requirements
- DSGVO-konform
- Skalierbarkeit für bis zu 20.000 Nutzer
- Performance
- Kein Overengineering
- Günstige Managed Services
- EU-only Datenhaltung

## Constraints/Compliance
- Keine neuen DB Server
- Security Review in 8 Wochen
- Compliance mit DSGVO und SAP-Rollenmodelle
