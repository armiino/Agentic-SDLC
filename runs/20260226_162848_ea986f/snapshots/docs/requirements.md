# Requirements

## Functional Requirements

1. Kundenportal zur Erstellung von Angeboten
2. Rechnungsdownload für Bestellungen 
3. Login-System mit Passwort und optional Single Sign-On (SSO)
4. Rollensystem (Admin, User, Manager, Support)    
5. Logging und Audit Trails
6. SAP-Integration für Stammdaten
7. Kein neuer Datenbankserver einrichten
8. Managed Services nutzen
9. API-Schicht implementieren 
10. Verschlüsselung (TLS)
  
## Non-functional Requirements

1. Skalierbarkeit für bis zu 20.000 Benutzer
2. DSGVO-Konformität
3. GDPR-konforme Datenverarbeitung und Backup
4. Echtzeit-Funktionen wie Push Notifications

## Constraints/Compliance

- Kein neuer Datenbankserver einrichten
- Managed Services nutzen
- Verschlüsselung (TLS)
- DSGVO-Konformität
