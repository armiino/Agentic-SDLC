# Architektur
Die Projektarchitektur soll die folgenden Anforderungen berücksichtigen:
- **API Layer**: Eine API wird implementiert, um Funktionalitäten wie Angebotserstellung und Kundendatenzugriff zu ermöglichen.
- **Sicherheit**: OAuth2 für Authentifizierung und Autorisierung.
- **Skalierbarkeit**: Die Architektur sollte flexibel genug sein, um Managed Services zu nutzen, ohne den Anforderungen an die Skalierbarkeit zu verletzen.
