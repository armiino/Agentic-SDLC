# Architecture Overview

1. Customer Portal
   - Web-first approach initially, mobile later.

2. User Authentication & Authorization
   - Email/password login (MVP)
   - SSO integration (optional)

3. Data Security and Compliance
   - GDPR compliance measures including data privacy policies, access control roles, audit logs.

4. Integration Points
   - API layer to interface with SAP for product data, pricing, and rebate logic.
