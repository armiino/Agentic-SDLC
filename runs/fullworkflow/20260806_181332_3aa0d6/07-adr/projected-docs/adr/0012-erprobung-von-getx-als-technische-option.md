# ADR-0012: Erprobung von GetX als technische Option

Status: accepted
Core-Item: ARCH-38

## Kontext

Im Zusammenhang mit dem Technologiestack wurde eine konkrete technische Option benannt, die noch nicht als endgültige Festlegung beschrieben ist. Das Material hält fest, dass das Paket GetX berücksichtigt und in der Umsetzung erprobt werden soll; die Begründung beschreibt dies als konkrete Architektur- und Stack-Option.

## Entscheidung

Wir berücksichtigen GetX als technische Option und erproben das Paket in der Umsetzung.

## Konsequenzen

Für Zustandsverwaltung oder verwandte technische Aufgaben besteht eine benannte Option, die gezielt bewertet werden kann. Gleichzeitig ist die Nutzung noch nicht als endgültig abgeschlossen festgelegt, sodass Erprobungs- und Bewertungsaufwand entsteht.

## Verwandte Core-Items

- REQ-54 — Das Paket GetX soll als technische Option berücksichtigt und in der Umsetzung erprobt werden.
- ARCH-37 — Für die Entwicklung soll Flutter mit Dart verwendet werden, um die plattformübergreifende Umsetzung zu unterstützen.
- REQ-53 — Für die Entwicklung soll Flutter mit Dart verwendet werden, um die plattformübergreifende Umsetzung zu unterstützen.
