# ADR-0011: Namenssuche in der Profiluebersicht

Status: accepted
Core-Item: ARCH-16

## Kontext

Fuer die Profiluebersicht wurde festgelegt, dass eine Suchleiste vorhanden sein soll, damit Profile schnell nach Namen gefunden werden koennen. Diese Vorgabe konkretisiert die funktionale Ausgestaltung der Uebersicht.

## Entscheidung

Wir statten die Profiluebersicht mit einer Suchleiste aus, ueber die Profile schnell nach Namen gefunden werden koennen.

## Konsequenzen

Die Auffindbarkeit von Profilen in der Uebersicht wird verbessert und der Zugang zu gesuchten Bewohnerprofilen wird beschleunigt. Gleichzeitig muss die Profiluebersicht die Suchfunktion verbindlich unterstuetzen.

## Verwandte Core-Items

- REQ-17 — Auf der Profilübersicht muss eine Suchleiste vorhanden sein, um Profile schnell nach Namen zu finden.
- L3-REQ-006 — Die Profilübersicht sollte zusätzlich zur Namenssuche eine Sortierung nach Name und optional nach zuletzt aktualisiert unterstützen.
