# ADR-0019: Suche und Beschreibungsmuster fuer Kommunikationsseiten

Status: accepted
Core-Item: ARCH-24

## Kontext

Fuer Kommunikationsseiten wurde eine Suchfunktion festgelegt. Damit Suche und spaetere Filterung funktionieren, muss laut Material ein standardisiertes Beschreibungsmuster fuer Kommunikationseintraege definiert werden. Die Entscheidung betrifft damit sowohl Nutzung als auch Struktur der erfassten Inhalte.

## Entscheidung

Wir stellen auf Kommunikationsseiten eine Suchfunktion bereit und legen dafuer ein standardisiertes Beschreibungsmuster fuer Kommunikationseintraege zugrunde.

## Konsequenzen

Kommunikationswissen kann gezielter durchsucht und spaeter auch besser gefiltert werden. Gleichzeitig bindet die Entscheidung die Erfassung von Kommunikationseintraegen an ein systematisches Beschreibungsmuster, das definiert und konsequent genutzt werden muss.

## Verwandte Core-Items

- REQ-28 — Auf den Kommunikationsseiten soll eine Suchfunktion vorgesehen werden; dafür muss ein systematisches Beschreibungsmuster für die Eingabe von Kommunikationsweisen definiert werden, damit später besser gesucht und gefiltert werden kann.
