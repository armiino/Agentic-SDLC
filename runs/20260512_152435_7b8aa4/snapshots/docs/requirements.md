# Anforderungen

## Funktionalitäten
- Kundenportal mit Web-Anwendung
- Login per E-Mail und Passwort
- Rollenmodell (Admin, Normaler User, Manager, Support)
- SAP Integration für Produktinformationen und Preise
- Angebotsgenerierung
- Rechnungsdownload

## Nicht-funktionale Anforderungen
- DSGVO-konforme Lösung
- Keine neue Datenbank (Managed Services verwenden)
- Skalierbarkeit für bis zu 20.000 Nutzer
- Sicherheitsanforderungen (TLS, OAuth, Logging, Audit Trails)

## Beschränkungen/Compliance
- DSGVO-konforme Lösung (Double Opt-In, Auftragsverarbeitungsvertrag, Löschkonzepte)
- Keine native App für Mobilgeräte
- Kein Overengineering
