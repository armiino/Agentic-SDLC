# ADR-0027: Hilfe-Tour beim Erstlogin und aufrufbarer Hilfebereich

Status: accepted
Core-Item: ARCH-34

## Kontext

Fuer die Unterstuetzung der Nutzer wurde festgelegt, dass eine Hilfe-Funktion oder ein Tutorial vorgesehen werden soll. Als bevorzugte Auspraegung nennt das Material eine kurze Tour beim ersten Login sowie einen spaeter erneut aufrufbaren Hilfebereich.

## Entscheidung

Wir sehen eine Hilfe-Funktion vor, idealerweise als kurze Tour beim ersten Login und zusaetzlich als spaeter erneut aufrufbaren Hilfebereich.

## Konsequenzen

Nutzer erhalten einen gefuehrten Einstieg und koennen Hilfe bei Bedarf spaeter erneut abrufen. Das unterstuetzt Einarbeitung und Nachschlagen innerhalb der App. Gleichzeitig muss die Interaktionsgestaltung einen Erstlogin-Ablauf sowie einen dauerhaften Zugang zur Hilfe vorsehen.

## Betrachtete Alternativen

Die Hilfe kann als Tutorial beziehungsweise Hilfebereich umgesetzt werden; bevorzugt ist eine kurze Tour beim ersten Login plus spaeterer erneuter Aufruf.

## Verwandte Core-Items

- REQ-46 — Eine Hilfe-Funktion oder ein Tutorial soll vorgesehen werden, idealerweise als kurze Tour beim ersten Login und als später erneut aufrufbarer Hilfebereich.
