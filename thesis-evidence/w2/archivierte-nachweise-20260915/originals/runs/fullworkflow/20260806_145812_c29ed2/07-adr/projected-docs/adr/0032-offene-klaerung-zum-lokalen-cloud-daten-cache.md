# ADR-0032: Offene Klaerung zum lokalen Cloud-Daten-Cache

Status: accepted
Core-Item: ARCH-40

## Kontext

Im Material ist festgehalten, dass geklaert werden muss, ob und wie Cloud-Daten lokal auf dem Geraet gespeichert oder gecacht werden sollen. Dokumentiert ist damit eine offene Architekturfrage zur lokalen Datenhaltung.

## Entscheidung

Wir halten die Frage offen, ob und wie Cloud-Daten lokal auf dem Geraet gespeichert oder gecacht werden.

## Konsequenzen

Es wird keine vorschnelle Festlegung zur lokalen Datenhaltung getroffen. Gleichzeitig bleibt eine architektonisch relevante Frage fuer Offline-Verhalten, Datenzugriff und Geraetespeicherung noch offen und muss spaeter entschieden werden.
