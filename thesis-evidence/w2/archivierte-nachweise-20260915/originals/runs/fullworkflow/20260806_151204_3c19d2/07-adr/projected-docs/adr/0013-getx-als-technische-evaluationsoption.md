# ADR-0013: GetX als technische Evaluationsoption

Status: accepted
Core-Item: ARCH-38

## Kontext

Fuer die technische Umsetzung wurde festgehalten, dass das Paket GetX als Option beruecksichtigt und in der Umsetzung erprobt werden soll. Die Aussage dokumentiert eine Technologieoption fuer den Stack, jedoch noch keine endgueltige Festlegung.

## Entscheidung

Wir beruecksichtigen GetX als technische Option und erproben das Paket in der Umsetzung.

## Konsequenzen

Die Entwicklung behaelt Spielraum, GetX praktisch auf Eignung zu pruefen, bevor eine endgueltige technische Verbindlichkeit entsteht. Gleichzeitig ist die Entscheidung bewusst vorlaeufig, sodass Architektur- und Implementierungsdetails von den Ergebnissen der Erprobung abhaengen koennen.

## Verwandte Core-Items

- REQ-54 — Das Paket GetX soll als technische Option berücksichtigt und in der Umsetzung erprobt werden.
- ARCH-37 — Für die Entwicklung soll Flutter mit Dart verwendet werden, um die plattformübergreifende Umsetzung zu unterstützen.
