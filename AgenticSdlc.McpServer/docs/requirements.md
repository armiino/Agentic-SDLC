# Requirements
## Functional Requirements
- FR1: The system must support user registration.
- FR2: Users should be able to log in using their credentials.

## Non-functional Requirements
- NFR1: The application’s response time under normal load shall not exceed three seconds.
- NFR2: System availability needs to be at least 99.5%.

## Constraints/Compliance
Compliance with GDPR when handling European user data (citation marker T001)
