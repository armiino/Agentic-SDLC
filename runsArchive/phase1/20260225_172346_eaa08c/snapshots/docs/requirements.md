# Functional Requirements
- Portal for customers
- Generate offers and invoices
- User login with email/password
- SAP integration
- API layer for integrations
- Logging mechanisms
- Compliance with GDPR

# Non-functional Requirements
- Performance: Scalability to handle up to 20,000 users
- Security measures: TLS encryption, OAuth authentication for API access
- Time-to-market constraint of an MVP in 8 weeks
- Maintainability and documentation for compliance with security review processes
