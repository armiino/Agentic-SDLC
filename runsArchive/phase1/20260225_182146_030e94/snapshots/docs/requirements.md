# Anforderungen
## Funktionale Anforderungen:
- Kundenportal
- Angebote erstellen 
- Rechnungsdownload

## Nicht-funktionale Anforderungen:
- DSGVO-Konformität (Double-Opt-In, Logging, Verschlüsselung)
- API Layer
- Skalierbarkeit
- Compliance mit DSGVO
- Backup und Disaster Recovery Plan.

## Einschränkungen/Verpflichtungen: 
- Kein neuer DB Server
- Managed Services anstelle eigener Infrastruktur
- keine Overengineering
