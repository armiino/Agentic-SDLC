# Gefahren
1. Kein zentrales IAM System vorhanden, was die Integration von SSO erschweren könnte.
2. Die Frist für den MVP (8 Wochen) könnte durch zusätzliche Sicherheitsanforderungen nicht eingehalten werden.
3. Komplexe Authentifizierungsmechanismen (OAuth) könnten Zeit kosten und das Projekt verzögern.
