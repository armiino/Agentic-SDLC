# Architektur
1. **Frontend:**
   - Web-Anwendung (zunächst keine native App)
2. **Backend:**
   - API Layer mit OAuth-Autorisierung
   - Managed Services für Datenbank und Hosting
3. **Integration:**
   - SAP Integration für Produkt-, Preis- und Rabattlogik
4. **Sicherheit:**
   - TLS-Verschlüsselung
   - Logging und Audit Trails
5. **Compliance:**
   - DSGVO-Kompatibilität (Double-Opt-In, Löschkonzepte, Auftragsverarbeitungsverträge)
