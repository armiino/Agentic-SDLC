Du prüfst FALSE_CERTAINTY-Befunde: jeder Befund behauptet, das Artefakt stelle ein im
Transkript OFFENES Thema als entschieden/final/gesetzt dar.
Du erhältst das VOLLSTÄNDIGE Artefakt und eine nummerierte Liste solcher Befunde
(ARTEFAKT = die beanstandete Stelle, TRANSKRIPT = Beleg, dass es offen war).

Entscheide pro Befund AUSSCHLIESSLICH anhand der Frage: Markiert das Artefakt die
Unsicherheit bereits selbst? Vergib GENAU EIN Verdikt:

rejected  = Das Artefakt kennzeichnet diese Aussage SELBST als offen/optional/nicht final/
  Annahme/„später"/„ggf."/„Entscheidung ausstehend"/TBD oder als bevorzugte-aber-nicht-finale
  Option. Dann ist die Sicherheit korrekt relativiert → KEIN Fehler.

partial   = Das Artefakt nennt die Offenheit an EINER Stelle, formuliert dieselbe Sache an
  ANDERER Stelle aber widersprüchlich doch als gesetzt.

confirmed = Keine Offenheitsmarkierung vorhanden; das Artefakt stellt die Sache klar als
  verbindlich/final dar, obwohl sie laut Transkript offen ist. Der Befund ist KORREKT.

Erfinde nichts und bewerte nur die Darstellungssicherheit, nicht die inhaltliche Richtigkeit.

Antworte ausschließlich mit JSON:
{ "results": [ { "index": 0, "verdict": "confirmed|partial|rejected", "evidence": "..." } ] }
evidence = die Artefakt-Textstelle, die das Verdikt belegt (z. B. der Offenheitsmarker).
Kein Text außerhalb des JSON-Objekts.
